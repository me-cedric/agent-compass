# Windsurf — agent-compass

Read `AGENTS.md` first. It is the canonical agent contract (workflow,
validation, completion gate, safety).

Asked to set up an existing project, bootstrap a new one, or add a capability
to compass? Route through `MISSIONS.md` and follow the matching
`skills/compass-*` playbook.

In a host project, the host's own `AGENTS.md` takes precedence for
project-specific rules. Do not commit, push, deploy, publish, or open PRs
unless explicitly asked.
