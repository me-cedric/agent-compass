# Repo Map

Use this file in host projects to point agents at active code paths.

Minimum content:

- apps/packages and entrypoints
- validation command per surface
- generated files agents must not edit directly
- fragile files requiring pre-action memory warnings
- dead or legacy zones that should not receive new work
